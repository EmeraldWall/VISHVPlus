VisaryPDF

Read, edit, fill, sign and convert PDFs in one fast, lightweight Windows app — with OCR that runs right on your PC.

Coming soon to the Microsoft Store Windows 10 & 11 x64 & ARM64 No telemetry

Make searchable

Scanned pages become real text.

VisaryPDF adds an invisible text layer to scanned pages, so you can search, select and copy them. Recognition uses the OCR engine already built into Windows, so your documents never leave your PC.

Illustration of the Make searchable feature.

Everything in one app

The PDF tools you actually use.

No account, no ads, no cloud uploads. Open a PDF and get to work.

📖

Read comfortably

Tabs for several PDFs, continuous or two-page layouts, pinch to zoom, thumbnails, bookmarks and search with highlighted matches. Files reopen on the page where you left off.

✍️

Fill and sign

Fill text fields, check boxes and drop-downs. Sign by drawing, typing in a handwriting font, or using an image, then place it anywhere and add the date.

✏️

Edit

Change existing text in place, add new text, leave comments and highlights, and rotate, delete or extract pages. Every change can be undone.

🔄

Convert

Export to Word, plain text, PNG or JPEG. Turn images into a PDF, merge PDFs, or append pages to an open document.

🖨️

Print sharply

The standard Windows print dialog, with crisp vector output. Comments, highlights and filled-in form values print too.

🌗

Easy on the eyes

System, Light, Dark and pure Black themes, with optional page dimming for night reading. Full keyboard navigation and screen reader labels.

Getting Started

Open a PDF and go.

1

Install from the Store

Get VisaryPDF from the Microsoft Store when it launches. It runs on Windows 10 and 11, on both x64 and ARM64 PCs.

2

Make it your PDF app

In Menu > Settings, choose "Open PDFs with VisaryPDF". PDFs you open from File Explorer then land as tabs in one window.

3

Read, sign, convert

Everything lives in the floating tool bar. Press F1 any time for the full list of keyboard shortcuts.

Good to know: signatures are visual signatures, like "Fill & Sign" — certificate-based digital signatures aren't included. VisaryPDF can open and keep password protection, but can't add a password to a PDF. OCR needs a Windows language with the Optical character recognition feature, which English includes on most PCs.
