02 / HighlightsWhat you get

What's inside.

01

Read comfortably

Tabs for several PDFs, four page layouts, pinch to zoom, thumbnails, bookmarks and search with highlighted matches.

02

Fill and sign

Fill forms in place. Sign by drawing, typing in a handwriting font or using an image, and add the date.

03

Edit

Change existing text in place, add new text, comments and highlights, and rotate, delete or extract pages.

04

Convert

Export to Word, plain text, PNG or JPEG. Turn images into a PDF, merge PDFs or append pages.

05

On-device OCR

Make scanned PDFs searchable and copyable with the OCR built into Windows.

06

Print sharply

The standard Windows print dialog with vector output. Comments, highlights and form values print too.

First release: read, fill, sign, edit, print and convert PDFs, with on-device OCR for scanned documents, tabs, four page layouts and four themes.

Requirements
OSWindows 10 1809 or later, Windows 11
Architecturex64, ARM64
OCRA Windows language with OCR (English on most PCs)
ExportWord, TXT, PNG, JPEG

Good to know: signatures are visual signatures, like "Fill & Sign"; certificate-based digital signatures aren't included. VisaryPDF opens password-protected PDFs and keeps the protection, but can't add a password to a PDF.
